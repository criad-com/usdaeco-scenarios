# Retained research evidence

`spike_edit_semantics.py` records the original IFC wall and pipe experiments.
`revit/` retains the S1–S3 native API scripts, export, and port identity recipe.
These are historical evidence, not the integration gate or current setup instructions.

The S4 IFC adapter, S5 Bonsai runner and prototype schemas have been removed:
`usdaeco-sync` supplies the maintained host implementations and scenario runner;
core, pipe, build-up and wall supply the production schemas. Run the current
[family gate](../README.md) and [demo](../demo/README.md) instead.
