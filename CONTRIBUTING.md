# Contributing

Keep changes to the gate reproducible from the declared release tags. Run
the [checks](README.md#build-and-check), add a failing fixture for a new gate
rule, and record measured counts and execution limits in the change description.
Do not change released source checkouts or hide failed or unexecuted rows.

Use public repository identifiers in committed files and keep local mirror
settings outside this checkout. Contributions use the [MIT licence](LICENSE).
